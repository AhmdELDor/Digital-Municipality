# Cairo Font Setup

Download Cairo font files from Google Fonts:
https://fonts.google.com/specimen/Cairo

Required font weights:
- Cairo-Regular.ttf (400)
- Cairo-Medium.ttf (500)
- Cairo-SemiBold.ttf (600)
- Cairo-Bold.ttf (700)

Place the font files in this directory.

## Quick Setup:
1. Visit: https://fonts.google.com/specimen/Cairo
2. Click "Download family"
3. Extract the ZIP file
4. Copy the following files from the `static` folder:
   - Cairo-Regular.ttf
   - Cairo-Medium.ttf
   - Cairo-SemiBold.ttf
   - Cairo-Bold.ttf
5. Paste them in this `assets/fonts/` directory

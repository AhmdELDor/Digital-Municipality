# Digital Municipality - Admin Dashboard (Flutter)

## 📋 Project Overview

A comprehensive Arabic RTL admin dashboard for managing digital municipality services. This system enables government administrators to manage citizens, services, bills, projects, complaints, and more through a secure, feature-rich interface.

---

## 🎯 Key Features

- ✅ Arabic-only interface with full RTL support
- ✅ Secure admin authentication with OTP verification (Twilio)
- ✅ Role-based access control (Admin & Super Admin)
- ✅ Dynamic branding (logo, colors, dashboard name)
- ✅ Light & Dark mode support
- ✅ Firebase Cloud Messaging notifications
- ✅ Comprehensive activity logging
- ✅ Classical government-grade UI design (80% resolution)

## 🛠️ Technology Stack

### Frontend
- **Framework:** Flutter 3.x
- **Language:** Dart 3.x
- **State Management:** Provider / Riverpod
- **Navigation:** GoRouter
- **HTTP Client:** Dio
- **Local Storage:** SharedPreferences
- **Notifications:** Firebase Cloud Messaging (FCM)
- **Charts:** fl_chart
- **Image Handling:** cached_network_image, image_picker

### Backend API
- **Framework:** Laravel 12.x
- **Authentication:** Laravel Sanctum (Token-based)
- **Database:** MySQL/PostgreSQL
- **OTP Service:** Twilio

### Design System
- **Language:** Arabic (RTL)
- **Themes:** Light & Dark mode
- **Resolution:** 80% (Classical government UI)
- **Color Scheme:** Dynamic (configurable)

## 🔐 Authentication Flow

```
1. Admin enters phone number + password
2. System sends OTP via Twilio
3. Admin enters OTP code
4. System verifies OTP with backend
5. Backend returns Sanctum token
6. Token stored securely
7. Token included in all API requests
```

**Base URL:** `http://your-domain.com/api`
